# 🚀 은하 무역 연합

우주 식민지 개척단이 되어 생산하고 거래하며, **서로 다른 행성이 왜 무역을 하는지** 몸으로 깨닫는 비교우위 수업 게임입니다.

▶ **플레이:** https://kh31isle-prog.github.io/galaxy-trade/

설치나 가입 없이 웹 브라우저만 있으면 됩니다. 교사 기기 한 대를 프로젝터에 띄우고(전광판), 학생은 팀별 기기 한 대로 접속합니다. 크롬북·태블릿·휴대폰 모두 되고 학교 와이파이에서도 접속됩니다.

## 수업 정보

| 항목 | 내용 |
| --- | --- |
| 과목 | 통합사회2 · 무역 단원 |
| 핵심 개념 | 절대우위와 비교우위, 기회비용, 특화와 교역, 교역 조건, 상호 의존 |
| 인원 | 2인 1팀(팀당 기기 1대) + 교사 전광판 |
| 시간 | 약 45분 (보너스 라운드 포함 약 50분) |
| 준비물 | 교사 기기 1대, 프로젝터, 학생 기기(2명당 1대). 종이 학습지 필요 없음 |

## 학습 목표

- 절대우위와 비교우위를 구분한다.
- 기회비용을 계산해 각 행성이 무엇에 특화해야 하는지 판단한다.
- 특화와 교역이 양쪽 모두에게 이익이 되는 이유와 교역 조건의 범위를 설명한다.
- 자원 분포 차이와 기술 차이도 무역이 일어나는 이유임을 안다.
- (보너스) 무역 의존의 위험, 보호무역, 공급 충격이 교역에 주는 영향을 설명한다.

## 게임 구성

**4개의 행성** — 볼카노(화산), 아쿠아(해양), 테라(개척 본부), 프로스트(얼음). 행성마다 에너지·식량을 만드는 능력과 그 행성에만 있는 특산품이 다릅니다. 학생은 자기 행성의 능력만 알고, 다른 행성의 사정은 흥정하며 알아냅니다.

**점수** — 에너지 × 식량 × (1 + 0.3 × 건물 수). 순위는 점수가 아니라 *혼자 살 때의 최고 점수 대비 성장률*로 매겨서, 가장 약한 행성도 1등을 노릴 수 있습니다.

**개척 미션** — 미션 건물의 재료는 모두 다른 행성의 특산품이라 거래 없이는 지을 수 없습니다. 두 미션을 끝낸 팀에게는 대형 미션이 열립니다.

| 단계 | 내용 | 시간 |
| --- | --- | --- |
| 1라운드 · 고립 시대 | 워프 폭풍으로 통신 두절. 무역 없이 혼자 생산 | 5분 |
| 2라운드 · 교환 시대 | 생산은 그대로 두고 거래만 | 7분 |
| 3라운드 · 특화 시대 | 잘하는 것에 몰아서 생산하고 교역 | 10분 |
| 🏆 본선 시상식 | 최고 성장, 최다 교역, 첫 완공, 대역전 | 2분 |
| ⚡ 보너스 라운드 (선택) | 행성별 위기 사건(화산 대분화, 운석 충돌, 반도체 공급 차질, 기술 혁신) + 교사가 고르는 무역 장벽 | 7분 |
| 📊 분석 | 행성 능력 공개, 라운드별 변화, 교역 조건, 특화 점검, 교역망, 생각 나누기 | 10~15분 |

## 진행 방법

1. 교사가 게임 주소에서 **교사 전광판 열기** → 팀 수 입력 → **행성 배정하고 시작**
2. 전광판에 뜬 방 코드 4자리와 팀 번호를 학생에게 안내
3. 학생은 같은 주소에서 **학생으로 참가** → 방 코드와 팀 번호, 팀원 이름 입력
4. 학생은 일꾼 12명을 발전소와 농장에 배치하고 **✅ 배치 완료**를 누릅니다.
5. 교사는 전광판 맨 위 노란 버튼(생산 확정 → 라운드 종료 → 다음 라운드)만 누르며 넘어갑니다. 실수로 넘겼다면 **↶ 방금 진행 취소**로 되돌립니다.
6. 수업이 끝나면 분석 화면의 **📥 결과 내려받기**로 팀별 기록·거래 내역·생각해 보기 답을 엑셀로 받습니다.

> 전광판 창이 모든 거래를 처리하므로 수업이 끝날 때까지 닫지 마세요.
> 수업 전에 혼자 시험하려면 전광판 아래 **학생 화면 미리보기**에서 행성을 바꿔 가며 해 보세요.

## 주요 기능

- **흥정은 말로, 체결은 앱으로** — 제안·수락·거절·역제안. 보내기 전에 거래 후 점수가 미리 보입니다.
- **개척지 마을** — 발전소·농장·특산품 건물·창고·우주항이 있는 3×3 마을. 미션 건물을 지을수록 마을이 채워집니다.
- **은하 전광판** — 교역 항로와 화물선, 완공 뉴스, 순위 변동, 팀별 배치 완료 표시
- **디지털 기록지** — 라운드별 기록이 자동으로 남고, 팀별로 생각해 보기 질문에 답합니다.
- **꼼수 방지** — 공짜 몰아주기 불가, 한 번에 40개 상한, 수락 순간 재고 재확인, 교사의 거래 되돌리기

## 내 데이터베이스로 쓰기 (선택)

기본 주소 그대로 쓰면 제작자의 무료 서버를 모든 사용자가 나눠 씁니다. 정규 수업에 자주 쓰신다면 선생님 본인 Firebase 데이터베이스를 연결하세요(처음 한 번, 약 10분).

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **Realtime Database**를 만듭니다(위치: 싱가포르, 잠금 모드).
2. **규칙** 탭에 아래를 붙여 넣고 게시합니다.
   ```json
   { "rules": { "rooms": { "$code": {
       ".read": "$code.matches(/^[0-9]{4}$/)",
       ".write": "$code.matches(/^[0-9]{4}$/)" } } } }
   ```
3. **데이터** 탭 맨 위 주소(`https://…firebasedatabase.app`)를 복사합니다.
4. 게임 첫 화면의 **⚙️ 내 Firebase 연결**에 붙여 넣고 저장합니다.
5. 전광판의 **📋 참가 링크 복사**로 받은 링크를 학생에게 줍니다.

## 교사용 자료

라운드별 진행 대본, 분석 시간 질문과 정리, 문제 해결 방법은 교사용 진행 안내서에 정리되어 있습니다. 행성별 능력과 정답이 들어 있어 학생에게는 공개하지 않습니다. 필요하신 선생님은 제작자에게 연락해 주세요.

## 기술 정보

- HTML 파일 하나로 된 웹 게임입니다(GitHub Pages에 `index.html`로 올림).
- 교사 전광판이 게임 상태를 관리하고, Firebase Realtime Database로 학생 기기와 연결합니다. 바뀐 부분만 주고받아 전송량이 적습니다.
- 주소 뒤에 `?db=<데이터베이스 이름>`을 붙이면 그 데이터베이스로 연결합니다(⚙️ 내 Firebase 연결이 자동으로 만들어 줌).
- 파일을 그냥 열면 교사 기기 한 대에서만 시험할 수 있습니다.
