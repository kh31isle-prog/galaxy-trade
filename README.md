# 🚀 은하 무역 연합

우주 식민지 개척단이 되어 생산하고 거래하며, 서로 다른 행성이 왜 무역을 하는지 몸으로 깨닫는 비교우위 수업 게임입니다.

▶ **플레이:** https://kh31isle-prog.github.io/galaxy-trade/

## 수업 정보

| 항목 | 내용 |
| --- | --- |
| 과목 | 통합사회2 · 무역 단원 |
| 핵심 개념 | 절대우위와 비교우위, 기회비용, 특화와 교역 |
| 인원 | 2인 1팀 (팀당 기기 1대) + 교사 전광판(프로젝터) |
| 시간 | 약 45~50분 |

## 게임 구성

- **4개의 행성:** 볼카노 · 아쿠아 · 테라 · 프로스트. 행성마다 에너지·식량 생산 능력과 특산품이 다릅니다.
- **점수:** 에너지 × 식량 × (1 + 0.3 × 건물 수). 순위는 혼자 살 때의 최고 점수 대비 성장률로 매깁니다.
- **라운드:**
  1. 고립 시대: 무역 없이 혼자 생산
  2. 교환 시대: 생산은 그대로 두고 거래만
  3. 특화 시대: 잘하는 것에 집중하고 교역
  - 🏆 본선 시상식
  - ⚡ 보너스 라운드 (선택): 운석 충돌, 기술 혁신, 무역 장벽, 반도체 공급 차질
- **분석:** 행성 능력 공개, 라운드별 변화, 교역 조건, 특화 점검, 교역망

## 진행 방법

1. 교사가 게임 주소에서 **교사 전광판 열기** → 팀 수 입력 → **행성 배정하고 시작**
2. 전광판에 뜬 방 코드 4자리와 팀 번호를 학생에게 안내
3. 학생은 같은 주소에서 **학생으로 참가** → 방 코드와 팀 번호 입력
4. 교사는 전광판 위쪽 노란 버튼을 눌러 단계를 넘깁니다.

전광판 창은 수업이 끝날 때까지 닫지 마세요.
